# Contributing

Katkılar memnuniyetle kabul edilir.

## Önerilen Katkı Alanları

- Yeni Linux disk troubleshooting senaryoları
- Ubuntu, Debian, Rocky Linux, AlmaLinux farkları
- LVM, RAID, LUKS, ZFS, btrfs örnekleri
- Cloud disk genişletme senaryoları
- Gerçek üretim ortamı notları

## Pull Request Öncesi

- Komutların tehlikeli olup olmadığını belirtin.
- Production ortam uyarılarını ekleyin.
- Açıklamaları beginner-friendly yazın.
- Mümkünse örnek çıktı ekleyin.
